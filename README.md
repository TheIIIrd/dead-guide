# Досье героев Deadlock

Неофициальные гайды по героям Deadlock для новичков в виде детективных досье: Abrams и Paradox. Статичный сайт без сборки и зависимостей.

Внизу экрана закреплён счётчик душ (с учётом 600 стартовых). Двигаешь его, и страница пересчитывает уровень, очки способностей, купленные предметы, бонусы за вложения и урон способностей под текущий момент матча. Кнопка «Режим катки» открывает компактный экран для телефона рядом с клавиатурой: следующая покупка с полоской накопления, куда вложить очко способности, комбо и подсказки против выбранных соперников.

## Структура

```
index.html            картотека: обложки всех досье
assets/
  dossier.css         общие стили
  dossier.js          общий движок: счётчик, хроника покупок, режим катки, картотека соперников, меню дел
  heroes.js           реестр героев: из него строятся картотека и меню дел
abrams/
  index.html          тексты досье Abrams
  hero.js             данные Abrams: предметы, фазы, порядок улучшений, соперники, формулы способностей
paradox/
  index.html
  hero.js
```

## Открыть локально

Открой `index.html` в любом браузере. Сервер не нужен. Шрифты подгружаются с Google Fonts; без интернета страница работает, но со шрифтами по умолчанию.

## Опубликовать на GitHub Pages

1. Создай пустой репозиторий на GitHub и залей туда содержимое этой папки:

   ```bash
   git init
   git add .
   git commit -m "Initial commit: Deadlock hero dossiers"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```

2. В репозитории открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` запускается при каждом пуше в `main` и выкладывает всё, кроме служебных файлов. Если первый запуск прошёл до шага 2 и упал, перезапусти его во вкладке **Actions** (Run workflow).
4. Адрес сайта появится в **Settings → Pages**: `https://<логин>.github.io/<репозиторий>/`. Досье открываются по адресам `.../abrams/` и `.../paradox/`, режим катки — с `#katka` на конце.

## Как добавить героя

1. Скопируй папку `paradox/` под именем нового героя, например `haze/`.
2. В `haze/index.html` перепиши тексты. В `haze/hero.js` — данные: `id`, предметы (`ITEMS`), фазы покупок (`PHASES`), порядок улучшений (`UPG`), соперников (`RIVALS`) и функцию `compute`, которая считает цифры на карточках способностей.
3. Добавь одну запись в `assets/heroes.js`: имя, номер дела, путь, роль, цвет папки. Картотека и меню дел на всех страницах обновятся сами.
4. Если нужен свой оттенок фона папки на странице героя, добавь в `assets/dossier.css` класс вроде `.hero-paradox` и повесь его на `<body>`.

## Откуда данные

- Статы героев, способностей и предметов, бонусы за вложения и кривая уровней взяты из файлов игры (`heroes.vdata`, `abilities.vdata`), сборка от 9 октября 2026.
- Экономика душ: [deadlock.wiki/Souls](https://deadlock.wiki/Souls).
- Урон способностей посчитан до вычета сопротивлений цели.
- Счётчик считает, что все души, включая 600 стартовых, уходят на билд по порядку. Уровень растёт только от душ сверх стартовых: в файлах игры пороги уровней указаны без них (по [вики](https://deadlock.wiki/Boon) уровень 0 = 600 душ, уровень 1 = 800).
- После балансных патчей цифры могут устареть.
