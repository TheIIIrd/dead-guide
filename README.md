# Досье Abrams

Неофициальный гайд по герою Abrams из игры Deadlock в виде детективного досье. Одна статичная страница без сборки и зависимостей.

Внизу экрана закреплён счётчик душ. Двигаешь его, и страница пересчитывает уровень, очки способностей, купленные предметы, бонусы за вложения и урон способностей под текущий момент матча.

## Открыть локально

Открой `index.html` в любом браузере. Сервер не нужен. Шрифты подгружаются с Google Fonts; без интернета страница работает, но со шрифтами по умолчанию.

## Опубликовать на GitHub Pages

1. Создай пустой репозиторий на GitHub и залей туда содержимое этой папки:

   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```

2. В репозитории открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` запустится при каждом пуше в `main`. Если первый запуск прошёл до шага 2 и упал, перезапусти его во вкладке **Actions** (Run workflow).
4. Адрес сайта появится в **Settings → Pages** и в логе шага Deploy: `https://<логин>.github.io/<репозиторий>/`.

## Откуда данные

- Статы героя, способностей и предметов, бонусы за вложения и кривая уровней взяты из файлов игры (`heroes.vdata`, `abilities.vdata`), сборка от 9 октября 2026.
- Экономика душ: [deadlock.wiki/Souls](https://deadlock.wiki/Souls).
- Урон способностей на странице посчитан до вычета сопротивлений цели.
- После балансных патчей цифры могут устареть. Данные лежат в начале скрипта в `index.html` (константы `LEVEL_GOLD`, `INV`, `ITEMS`, `PHASES`).
