# Досье героев Deadlock

Неофициальные гайды по героям Deadlock в виде детективных досье: Abrams и Paradox. Статичный сайт без сборки и зависимостей.

Внизу экрана закреплён счётчик душ. Двигаешь его, и страница пересчитывает уровень, очки способностей, купленные предметы, бонусы за вложения и урон способностей под текущий момент матча. Кнопка «Режим катки» открывает компактный экран для телефона рядом с клавиатурой: следующая покупка, куда вложить очко способности, комбо и подсказки против выбранных соперников.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Досье Abrams: тексты и данные героя в `window.HERO` |
| `paradox.html` | Досье Paradox: тексты и данные героя в `window.HERO` |
| `dossier.css` | Общие стили; цвет папки героя задаётся классом вроде `.hero-paradox` |
| `dossier.js` | Общий движок: счётчик душ, хроника покупок, режим катки, картотека соперников |

## Открыть локально

Открой `index.html` в любом браузере. Сервер не нужен. Шрифты подгружаются с Google Fonts; без интернета страница работает, но со шрифтами по умолчанию.

## Опубликовать на GitHub Pages

1. Создай пустой репозиторий на GitHub и залей туда содержимое этой папки:

   ```bash
   git init
   git add .
   git commit -m "Initial commit: Deadlock hero dossiers"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```

2. В репозитории открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` запускается при каждом пуше в `main` и выкладывает все `.html`, `.css` и `.js` из корня. Если первый запуск прошёл до шага 2 и упал, перезапусти его во вкладке **Actions** (Run workflow).
4. Адрес сайта появится в **Settings → Pages** и в логе шага Deploy: `https://<логин>.github.io/<репозиторий>/`. Режим катки открывается сразу по ссылке с `#katka` на конце.

## Как добавить героя

1. Скопируй `paradox.html` под именем нового героя.
2. Перепиши тексты и объект `window.HERO`: предметы (`ITEMS`), фазы покупок (`PHASES`), порядок улучшений (`UPG`), соперников (`RIVALS`) и функцию `compute`, которая считает цифры на карточках способностей.
3. Поправь ярлык дела в `<nav class="spine">`: сейчас он переключает между двумя досье, для третьего героя туда понадобится выбор из списка.
4. Если нужен свой цвет папки, добавь в `dossier.css` класс вроде `.hero-paradox` и повесь его на `<body>`.

## Откуда данные

- Статы героев, способностей и предметов, бонусы за вложения и кривая уровней взяты из файлов игры (`heroes.vdata`, `abilities.vdata`), сборка от 9 октября 2026.
- Экономика душ: [deadlock.wiki/Souls](https://deadlock.wiki/Souls).
- Урон способностей на страницах посчитан до вычета сопротивлений цели.
- После балансных патчей цифры могут устареть.
